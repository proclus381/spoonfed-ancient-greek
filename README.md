# Spoonfed Ancient Greek

**An Anki deck that teaches Ancient Greek one new thing at a time: 4,735 sentences in the order of *Athenaze*,
each with natural-sounding audio.**

Every sentence brings exactly one new word, ending, form or construction. Everything else in it you have
already seen. You hear it, understand it and recall it, and by the end you have met every form in the grammar.

**It is a complete beginner course on its own.** You can start from zero, and you need no textbook, class or
other course. The only things to do alongside it are reading real Greek and listening to Greek
(see *Alongside the deck*).

**It also works for experienced readers.** If you already read Ancient Greek but have learned it through
the written page, the deck trains what reading alone doesn't: understanding Greek by ear, at speed, and
producing it yourself (say every sentence aloud). Most sentences will be easy for you, so raise the number of
new cards a day (see *Deck options*).

## Get started

1. **Download** `Spoonfed_Ancient_Greek.apkg` from the [Releases](../../releases) page.
2. **Import** it in Anki (File → Import). The audio is inside.
3. **Set the deck options** (below), then do 15–25 new sentences a day.

**Updates** import over the old version. Your review history is kept.

## What's in the deck

- **4,735 sentences, 9,470 cards.** Each sentence has a listening card and a cloze card.
- **Purely n+1.** Each sentence brings exactly one new item: a word, an ending or form, a verb stem, a set
  phrase, a construction, or a later sense of a word.
- **Follows the syllabus of *Athenaze* I–II (Italian edition, ch. 1–31) and *Meletemata*,** chapter by
  chapter. Chapter 32 adds grammar from Smyth's *Greek Grammar* that the book does not treat.
- **Every form.** Every cell of every inflection table in Smyth and in Wiktionary's Ancient Greek grammar
  tables has a card. That means every verb ending, and every case, number and gender of every noun, adjective,
  pronoun and participle type.
  - Within a chapter, the forms of one table come one after the other.
  - The dual is kept bare: one card per dual ending.
- **Natural Greek.** The sentences are composed for the deck. Their word order follows what each sentence
  presents as given or new (after Dik and Mastronarde), checked against Attic prose. The classical passages that
  *Athenaze* quotes are given in their authors' own words.
- **Audio for every sentence,** read by the ElevenLabs voice *Giassiranis Dimitrios* in the modern
  pronunciation of Greek (see *Pronunciation*).
- **No sentence is taken from *Athenaze* or *Meletemata*.** The books gave only the order of what is taught.
  A few everyday phrases (ποῦ ἐστιν ὁ κύων;) naturally occur in both.

## Why listening and cloze, not parsing?

- **Grammar analysis teaches you to work a sentence out:** identify the ending, find the case, look up the
  paradigm, put the meaning together.
- **That's useful, but it isn't reading.** Fluent readers understand Greek directly, left to right, without
  decoding each form.

This deck trains that directly:

- **Listening:** you understand whole sentences in real time, in order, without stopping to parse.
  - The input is comprehensible: almost everything in each sentence is already known.
  - You meet each form many times, in context.
  - That is how a language becomes automatic, rather than something you calculate.
- **Cloze:** you recall the form yourself instead of recognising it.
  - Active retrieval is one of the best-established findings in memory research.
  - It fixes forms far more firmly than re-reading or analysing them.
- **Context:** every word and ending is learned inside a sentence, with its typical constructions. So you learn
  what goes with what (which case a verb takes, which particle goes where) along with the form itself.

Grammar still has its place: look things up when a form puzzles you. But the deck aims for what grammar tables
can't give you, which is recognising Greek fast enough to read it.

## Starting from zero

The first cards assume four things. None of them takes long.

1. **The alphabet.** Learn to read every letter, the breathings (ἁ / ἀ), the iota subscript (ᾳ) and the
   diphthongs, until you can read a line aloud without stopping. The table in
   [docs/pronunciation.md](docs/pronunciation.md) (§1) gives the sound of each letter, as the deck's audio says it.
2. **The accents.** There are three: acute (ά), grave (ὰ) and circumflex (ᾶ). The grave stands for an acute
   before another word. Accents sometimes tell two forms apart; you don't need the rules.
3. **A few grammar terms.**
   - **Case:** the ending shows a noun's role. Nominative: the subject. Genitive: "of". Dative: "to, for".
     Accusative: the object. Vocative: calling someone.
   - **Number:** singular, plural, and dual (for two). **Gender:** masculine, feminine, neuter.
     **Person:** I, you, he/she/it.
   - **Tense:** when the action happens and whether it is ongoing or done. **Mood:** statement, command, wish
     or possibility. **Voice:** active (doing), middle (doing for oneself), passive (being done to).
   - **Participle:** a verb used as an adjective ("loosing", "having loosed"). **Infinitive:** "to loose".
4. **The article** ("the"). The deck uses it from the first card without teaching it, so learn it by heart:

   | | masc. | fem. | neut. |
   |---|---|---|---|
   | nom. sg. | ὁ | ἡ | τό |
   | gen. sg. | τοῦ | τῆς | τοῦ |
   | dat. sg. | τῷ | τῇ | τῷ |
   | acc. sg. | τόν | τήν | τό |
   | nom. pl. | οἱ | αἱ | τά |
   | gen. pl. | τῶν | τῶν | τῶν |
   | dat. pl. | τοῖς | ταῖς | τοῖς |
   | acc. pl. | τούς | τάς | τά |

   It is the key to every noun ending.

## How to use it

### Deck options (once)

All of these are in the deck's options (the gear icon next to the deck → Options):

| Setting | Value | Why |
|---|---|---|
| Display order → New card gather order | **Deck** | |
| Display order → New card sort order | **Order gathered** | The n+1 design depends on the order. A card is easy only because the ones before it came first. Never shuffle the new cards. |
| Burying → Bury new siblings | **off** | A sentence's cloze card is placed a few cards after its listening card, so that both come up in the same session. With burying on, the cloze cards are held back for days. |
| Daily limits → New cards/day | **30–50** | That is 15–25 new sentences, and about an hour a day once the reviews build up. Experienced readers can go much higher, for example 100 or more, as long as the daily reviews stay manageable. |
| FSRS (older Anki: Advanced) → FSRS | **on**, desired retention about **0.90** | |

### Doing a card

- **Listening card:**
  1. Play the audio and understand the sentence before you look.
  2. Say the meaning aloud, in English or in your head.
  3. Check the Greek and the English.
  4. Repeat the Greek aloud once, imitating the audio.
- **Cloze card:**
  1. Read the whole sentence.
  2. Produce the missing word or ending from the hint.
  3. Say the whole sentence aloud.
- **Grade honestly:** *Again* if you didn't understand the audio, or the cloze answer was wrong.
- **When a new form arrives in a run of its paradigm** (σοφοῦ, σοφῷ, σοφῶν …), notice the pattern. When the run
  is over, write the paradigm out once by hand.
- **Don't cram.** Doing the reviews every day matters more than how many new cards you add.

### Alongside the deck

Only two things:

- **Try reading real Greek.** Every so often, pick an original text, such as Aesop's fables, and try a few
  lines. Don't expect to understand everything: each chapter of the deck makes more of it readable.
  [Perseus](https://www.perseus.tufts.edu/hopper/) has many classical texts with a click-to-look-up dictionary.
- **Listen to Greek.** Replay the audio of chapters you have finished, while walking or commuting.
  - **Free audio of *Athenaze* I** in a reconstructed ancient pronunciation, by Ioannis Stratakis:
    [ancientgreek.eu](https://ancientgreek.eu/edu/athenaze-1.html). It is the main Greek text of each chapter
    of book 1, 4 h 42 min in 16 mp3 files. You ask for the download link by email, as the page explains.
  - It is the edition whose chapters the deck follows, so each chapter's recording uses mostly words and
    grammar you have met by the end of that chapter in the deck. It is also a good way to hear the reconstructed pronunciation (see below).

When a word or form puzzles you, look it up:

- **Words:** [Logeion](https://logeion.uchicago.edu/) searches LSJ (Liddell–Scott–Jones, the standard
  Ancient Greek–English dictionary) and other dictionaries at once.
- **Grammar:** H. W. Smyth's *Greek Grammar*, free online at
  [Perseus](https://www.perseus.tufts.edu/hopper/text?doc=Perseus:text:1999.04.0007). The chapter 32 cards
  cite its paragraph numbers (§).

## Pronunciation

- **The deck's audio uses the modern pronunciation of Greek:** each letter is read with the sound it has
  today, with a stress accent.
- **Why:** half the deck is listening, so the audio has to sound like real, fluent speech. Only the modern
  pronunciation gets that from today's voices.
- **Know the reconstructed pronunciation too.** It is scholars' best estimate of how Athens sounded in
  Plato's time, and it or Erasmian is what most teachers and textbooks use. With it, spelling, endings, accents
  and verse rhythm make sense.
- **Choose one for reading aloud** and keep to it. Listening to both does no harm: Ioannis Stratakis's free
  recording of *Athenaze* I (see *Alongside the deck*) lets you hear a reconstructed one.
- **[docs/pronunciation.md](docs/pronunciation.md)** explains both, in plain terms, for beginners.

## Tools

The scripts that built and checked the deck are included.

| Script | What it does |
|---|---|
| `project/check2.py` | the n+1 checker. For every card it lists the items it brings and any problems: two new items, nothing new, unknown forms, items before their chapter. `tools/chk.sh` runs it on the whole deck. |
| `project/schemes.py` | sorts each noun, adjective and participle into its inflection scheme (Smyth §), so that the checker keys every cell |
| `project/morph.py`, `morph2.py`, `parts.py` | the paradigm generator the checker analyses forms with |
| `project/build.py` | builds the apkg (genanki) |
| `tools/deck_edit.py` | edits the deck safely: INSERT, REPLACE (keeps the note's ID), MOVE, EXTRAS (hints), DELETE |
| `tools/guid_check.py`, `tools/regress_notes.py`, `tools/items_dump.py` | note-ID safety and per-note regression |
| `work/phase3/paradigms/catalog.py` | every grammatical cell the syllabus can produce, and whether a card teaches it |
| `work/phase3/paradigms/known_at.py`, `mk_inserts.py` | the vocabulary a new card may use at its place; insert operations |
| `work/phase3/paradigms/group.py` | puts a paradigm's cards next to each other within a chapter |
| `work/phase3/paradigms/dualgen.py` | verb dual forms by rule |
| `tools/phase3/style4.py`, `work/phase3/infostructure/*.py` | the word-order checks (subject and object position, the One Lexical Argument Constraint, vocatives) and the reorder proposer |

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
tools/chk.sh                                     # the checker: 0 problems is the target
cd project && AUDIO_MODE=ext ../.venv/bin/python build.py   # → out/Athenaze_Companion_ch01-32_humanvoice.apkg
```

The built apkg refers to the clips (`athv_*.mp3`) but does not contain them. `out/audio_manifest.tsv` lists each
clip's file name and the text it reads. The released apkg has the clips inside.
